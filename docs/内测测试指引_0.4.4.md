## 一、这版改了什么：修「后台播放几分钟后就没声了」

有内测用户反馈：**App 放后台播放时，播放几分钟后就没声了。**

我们查过了，**先说结论**：不是你的手机或网络「坏了」，是**我们 App 自己的一个缺陷** —— 一次本该自己恢复的抖动，被我们当成了「彻底播不下去」。

### 1. 到底发生了什么（大白话）

播放时，手机和我们的服务器之间保持着**一条一直连着的线**（一篇文章要连着传好几分钟）。

这条线在**后台**特别容易断：手机系统的省电策略、锁屏、Wi-Fi 切到流量……都会把它掐断。

断了之后，**0.4.3 及以前的版本不会自己接上** —— 它只会停下来等你手动点一下「重试」。
可你在后台听东西的时候，谁会去点那个按钮？于是：

> **一次网络抖动 = 播放彻底停住。**

还有更糟的一层：出错的那一刻，手机系统会**把播放服务从「后台保护」里撤出来**
（Android 只在「正在播放 / 正在缓冲」时保护它）。所以有时候你回到 App 想说「点一下重试吧」，
连 App 本身都已经被系统回收了。

### 2. 这一版做了什么

| 以前 | 现在 |
|---|---|
| 网络抖一下 → 播放**彻底停住**，要手动点重试 | 网络抖一下 → **自动重连**，并从断掉的地方**接着播** |
| 手动点「重试」→ **从头开始**（听了 3 分钟就白听） | 手动点「重试」→ **从断掉的地方接着播** |
| 界面只说「播放失败」 | 界面会说「**网络不稳，正在重连…**」，接上后自动恢复 |
| （没有任何记录） | 断了、接上了都会**记到我们的后台** ⇒ 下次再遇到，我们能直接定位到是哪一类 |

**这一版没有新增任何功能，也没有改动你的数据。**

### 3. 一句实话：我们还不知道「是谁」掐断了那条线

可能是手机的省电策略、可能是锁屏、也可能是网络本身。
这一版能保证的是「**断了能自己接上**」；但如果你的手机把后台网络限制得很死，那可能接上也接不上。

⇒ 所以第三步里那两个设置**请务必开一下**（一分钟的事，能省掉很多麻烦）。

## 二、怎么更新（两条路，任选一条）

### 路线 A：App 内更新（推荐）

1. 打开「听匣」
2. 进「**设置**」→ 点「**版本**」这一行
3. 弹出「有新版本」→ 下载 → 装完

### 路线 B：浏览器手动下载

1. 浏览器打开 https://stashbox.cn/downloads/latest.apk
2. 下载完点安装
3. 系统问「已存在该应用，是否覆盖安装？」→ 选「**安装** / 继续」

### ⚠️ 很重要：请「覆盖安装」，不要卸载重装

| 做法 | 你的登录状态 / 收藏 / 下载好的音频 / 历史进度 |
|---|---|
| **覆盖安装**（直接装上去） | **全都在** |
| 卸载重装 | **全部丢失**，还要重新登录、重新下载 |

如果手机提示「无法安装」或「签名不一致」，**别卸载**，截图发给我们 —— 那是包的问题，我们来修。

## 三、更新后请做这几件事

### 1️⃣ 确认版本

「设置」→「版本」应显示 **0.4.4 (17)**。

### 2️⃣ 重点试一下：后台播放放满 10 分钟

这一版修的就是「几分钟」量级的问题，所以**请让它真的跑够时间**：

1. 打开 App，播一篇文章（等声音出来）；
2. 按 Home 键退到后台；
3. **静置 10 分钟**（中间不用管它，别反复切回来）；
4. 回到 App —— 声音应该还在放，进度应该接着走。

> ⚠️ **别只试几十秒**：早前一版我们自己的真机验证就只做了 25 秒，
> 而问题出现在好几分钟之后 —— 验得太短，等于没验。

如果中途声音停了，**先别手动点重试**，看看它是不是自己接上了（这是这一版最该看的现象）。

### 3️⃣ 给手机开两个设置（**这一版最该做的一件事**）

不同手机叫法不一样，大致在「设置 → 应用管理 / 电池 → 后台」这类地方：

| 要开什么 | 在哪找 | 为什么 |
|---|---|---|
| **允许自启动**（有的手机叫「自启动管理」） | 设置 → 应用管理 → 听匣 → 自启动 | 有些系统会禁止 App 自己后台运行 |
| **省电策略 → 无限制**（有的手机叫「后台高耗电允许」/「不受限制」） | 设置 → 电池 → 应用管理 → 听匣 → 省电策略 | **这是最常见的原因**：被限制成省电模式后，系统会限制 App 在后台的联网，播放的连接就会被掐断 |
| （小米/红米）**允许后台联网** | 设置 → 应用管理 → 听匣 → 省电策略 / 网络 | 同上 |

> 如果你用的是小米 / 红米（MIUI），上面三项基本都要开。
> 这不是我们偷懒 —— 这是国产 Android 的通行做法，开完之后「后台就停」这类问题会少很多。

### 4️⃣ 顺手用一轮（不用专门测，正常用就行）

- 剪藏一篇公众号文章（贴链接）
- 等它蒸馏出音频（一般 1～4 分钟）
- 播放一小段，听听声音和字幕
- 试**锁屏控制**：锁屏后能不能暂停 / 续播
- 试**断点续听**：退出 App 再进来，进度应接着上次

### 5️⃣ 请不要做这两件事

- ❌ **不要清除应用数据**（设置里的「清除数据 / 清除缓存」）
- ❌ **不要卸载重装**

理由：这些性能数据按「设备 + 安装」连续采集，中途清数据或重装会让数据断档 —— 反而帮不上忙。

## 四、遇到问题怎么反馈

**入口**：「设置」→「**意见反馈**」（或在文章详情页右上角「⋯ → 反馈」）

请带上这几样：

- 机型 + 系统版本（设置 → 关于手机）
- 「设置 → 版本」里看到的版本号
- 出了什么事（截图最好）
- **如果是「后台播放停了」**：请额外告诉我们
  - 停了的时候大概放到第几分钟？
  - 手机是锁着屏还是亮着屏？
  - 当时是 Wi-Fi 还是流量？
  - **第 3 步那两个设置开了没有？**

> 最后一条最关键 —— 有了它，我们才能分清「是我们代码的锅」还是「系统把网断了」。

**特别欢迎**：任何你觉得「别扭」「说明不清」「找不到」的地方 —— 哪怕它不是 bug，那也正是我们要改的。你现在遇到的别扭，是内测最值钱的部分。

## 五、已知问题（先说在前面，免得多花时间）

| 现象 | 说明 |
|---|---|
| 剪藏某些网站失败，提示「没能读出文章正文，可能页面要登录，或者内容要等网页加载完」 | 我们的抓取只走普通网页通道，**动态渲染的页面（内容要等 JS 加载）和需要登录的页面读不到**。这不是你的操作问题，换个来源的链接就行。 |
| 蒸馏一直没动静 | 蒸馏要跑真实的大模型，通常 1～4 分钟。超过 10 分钟还没动静再反馈给我们。 |
| 播放时偶尔要等几秒才出声 | 正在收集这个数据。**如果你网络差，这个等待会明显变长** —— 这正是我们想知道的，请告诉我们你在什么网络下遇到的。 |
| 通知栏里没有播放控制条 | 看 0.4.3 那版指引的「三、2️⃣」三步 —— 绝大多数情况自己就能修好。修不好请截图反馈，并附上机型与系统版本。 |
| **后台播放还是会停** | 这一版已经能自动重连了，但**如果手机把后台网络限制得很死，重连也可能接不上**。请先按「三、3️⃣」把设置开了；还不行请按「四」把信息发我们。 |

## 六、这一版我们做了什么（给愿意看细节的人）

**0.4.4（2026-10-26）**

- 播放中途遇到网络抖动时**自动重连**，并从断掉的地方接着播（带退避与次数上限，不无限重试耗电）
- 恢复期间界面显示「网络不稳，正在重连…」，并允许你随时暂停
- 手动点「重试」**保留播放位置**（此前会从头开始）
- 你主动暂停之后才到的失败，不再弹「播放失败」打扰你
- 新增两条记录：播放中断、以及中断后是否自动接上 ⇒ 下次同类反馈我们能直接定位

**0.4.3（2026-10-26）**

- 通知权限的判断收口成**一份**，现在能分清三种情况：已经开了 / 还能弹系统授权框 / **只能去系统设置**
- 设置页新增「播放通知」一行（通知栏控制条与推送通知共用同一个系统权限，之前设置里**只有推送那一行**）
- 「系统不会再弹授权框」时，改为**直接跳到系统的通知设置页**，不再弹一个系统不会响应的框
- 播放器页新增提示条，把「为什么没有控制条」和「现在能做什么」直接摆出来

**0.4.2（2026-10-25）**

- 加了「首屏加载」「音频启动」两个性能指标的客户端采集（数据只进我们的后台）
- 管理后台的总览页新增「月留存」卡片（运营看的，跟你的使用无关）
- 后台与客户端的事件名加了一层自动校验，防止埋点因为「名字对不上」而静默丢失

**没有别的改动 —— 你的数据、账号、文章都不会因为这次更新发生变化。**
