## 🎉 欢迎加入听匣内测

**听匣 = 把任何链接变成 30 秒音频**——复制链接 → 30 秒后听 30 分钟精华。

## 📱 安装步骤

### 第一步：下载 APK

1. **点链接**：[蒲公英短链 URL]
2. 或**扫二维码**：[二维码图片 URL]

### 第二步：允许安装（Android 8+ 必做）

下载后系统会提示：
- "不允许安装来自此来源的应用"
- 解决：**设置 → 应用 → 特殊权限 → 安装未知应用 → 浏览器/微信 → 允许**

### 第三步：安装并打开

1. 点 "安装"（约 30 秒）
2. 打开 "听匣"
3. **首次启动会看到 3 步引导**（按提示走）

## 🚀 使用 3 步走

### 步骤 1：复制链接

看到喜欢的文章（公众号 / 抖音 / 知乎 / 任何网页）：
- **长按复制链接**（标题下方的 URL）
- 或**分享 → 复制链接**

### 步骤 2：打开听匣

回到听匣 App：
- 自动检测剪贴板里的链接
- 弹窗 "是否蒸馏这篇文章？" → 点 **确认**
- （或手动粘贴到 App 输入框）

### 步骤 3：30 秒后听音频

- **30 秒蒸馏**（进度条显示）
- **30 分钟精华音频**自动出现
- 点 ▶ 播放（**支持后台播放 + 锁屏控制**）
- 听到喜欢的地方可以收藏 / 标签订阅 / 给反馈

## ❓ 常见问题

### Q1：链接蒸馏失败？

**A**：蒸馏成功率高但不是 100%。失败时会弹"重试"按钮 → 点击重新蒸馏。

### Q2：可以装在 iPhone 上吗？

**A**：本期只支持 Android。iOS 后续版本评估中。

### Q3：流量消耗大吗？

**A**：30 分钟音频 ≈ 30 MB（128 kbps 压缩）。用 WiFi 时几乎无感。

### Q4：可以分享给朋友吗？

**A**：内测期只对 100 用户开放，**先到先得**。

### Q5：如何给反馈？

- **App 内**：右下角"反馈"按钮
- **微信群**：内测群里 @ Hornet
- **Bug 报告**：微信群发 "Bug：xxx"

## 📋 注意事项

1. **Android 版本**：需要 Android 8.0+（API 26+）
2. **存储空间**：约 50 MB
3. **权限**：网络 / 前台服务 / 通知（**必给通知权限**，不然听不到后台播放控制）
4. **横屏播放**：支持（自动旋转）
5. **离线缓存**：本期**不支持**（正式版会有）
