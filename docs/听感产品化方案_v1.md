## §0 一句话定位

**听匣下半场的胜负手不是把 AI Harness 堆到 12 层，而是把「听感」这件事做成可量化、可反馈、可迭代的产品能力。** Harness 是手段，听感是目的 —— 别反过来。

## §1 三个业务闭环（产品目标）

### 闭环 1 · 听感质量闭环（CP3.7 系列，最大 ROI）

**现状**：`quality_score = 8.5` mock；`feedback` 表存了评分但**没回灌**到 prompt / 模型 / 路由。

**目标**：让"这篇听感好不好"从「主观感觉」变成「可量化分数 → 自动决策」。

**核心动作**：
- 评分维度从「单星」扩到 **4 维**（hook / 节拍 / outro / 节奏），每维独立 1-5 分
- 评分 < 3 星 → 自动入「重蒸馏」队列（强制用完整版模型 + 增加 review 步骤）
- 评分 > 4 星 + 听完率 > 80% → 提取改写片段进「few-shot 池」
- few-shot 池每次 Step 2 注入 top-5 高分样本

**Harness 升级**：第 9 层「Reflection」真正落地（不再是 mock score）。

**预期收益**：复听率 +30%（用户核心粘性指标）。

### 闭环 2 · 个性化改写（CP5.x 系列，差异化壁垒）

**现状**：所有用户拿到**同一份** hook / sections / outro。

**目标**：同一篇文章，两个用户改写出不同版本 —— 「你的听感 vs 大众听感」。

**核心动作**：
- 用户的反馈历史 + 跳过模式 + 听完模式 → 合成「用户听感画像」
- 画像特征：平均会话时长 / 跳过率 / 完听率 / 偏好金句节奏 / 偏好 hook 类型
- Step 2 prompt 注入 5-10 个 few-shot + 用户画像摘要（200 token 内）
- 同一文章两个用户 → 两个改写版本

**Harness 升级**：第 10 层「Memory」落地（跨任务的 context 复用）。

**预期收益**：student ¥9 → member ¥29 转化率 +20%（付费墙给个性化）。

### 闭环 3 · 多端一致性 + 离线优先（CP7.x 系列）

**现状**：Android 主做；通勤场景 80% 在地铁 / 电梯**无网 / 弱网**；客户端缺离线缓存策略。

**目标**：用户在通勤场景「听完率」从行业均值 60% → 85%+。

**核心动作**：
- 服务端蒸馏完成**立刻生成 3 种码率**（128k / 96k / 64k m4a），OSS 存 3 份
- 客户端下载策略：通勤时段自动预加载下一篇文章的音频 + 文稿（基于用户通勤时间规律）
- 客户端**持久化播放进度**到本地 sqlite（断网回到原位继续听）
- 客户端 AI 决策「何时预加载」（基于时段 + 位置 + 听感画像）

**Harness 升级**：产品层补「Delivery」而非 AI 层（用 AI 决策时机）。

**预期收益**：通勤场景听完率 60% → 85%+。

from sqlalchemy.ext.asyncio import AsyncSession

from .schemas import DistillContext, UserListeningPattern, RewriteExample

class PreDistillHook(Protocol):

    1. TierRouterHook: 选择 target_tier
    2. UserProfileHook: 加载 user_profile
    3. FewShotSelectorHook: 加载 few_shot_examples

        self,
        ctx: DistillContext,
        article: Article,
        db: AsyncSession,

class PostStepHook(Protocol):
    """每步完成后：打点 + 缓存 stage result（CP3.6.4）。
    
    实现：
    1. StageCacheHook: 把 step 输出写 Redis（key: stage:{task_id}:{step_name}，TTL 24h）

    3. LangfuseSpanHook: 关 Langfuse span

    async def __call__(
        self,
        ctx: DistillContext,
        step_name: str,
        output: Any,
        db: AsyncSession,

    """蒸馏完成后：自动评估 + 决定是否重蒸 + 更新画像。

#### C. DistillPipeline 重构（`backend/ai-service/distill/pipeline.py`）

**完整改写后**：
```python
class DistillPipeline:
    def __init__(
        self,
        llm: LLMClient,
        tts_client=None,
        db_session_factory=None,
        pre_hooks: list[PreDistillHook] | None = None,
        post_step_hooks: list[PostStepHook] | None = None,
        post_hooks: list[PostDistillHook] | None = None,
    ):
        self.llm = llm
        self._tts_client = tts_client
        self.session_factory = db_session_factory
        self.pre_hooks = pre_hooks or []
        self.post_step_hooks = post_step_hooks or []
        self.post_hooks = post_hooks or []
        self._current = DistillStatus.QUEUED

    async def run(self, ctx: DistillContext) -> DistillContext:
        start = time.time()
        self._current = DistillStatus.QUEUED
        log.info("distill_started", task_id=ctx.task_id, article_id=ctx.article_id)

        # 1. Pre-hooks：选择 tier + 加载 few-shot + 加载用户画像
        if self.pre_hooks and self.session_factory is not None:
            async with self.session_factory() as session:
                article = await session.get(Article, ctx.article_id)
                if article is None:
                    raise ValueError(f"article {ctx.article_id} not found")
                for hook in self.pre_hooks:
                    try:
                        await hook(ctx, article, session)
                    except Exception as e:
                        log.warning("pre_hook_failed_continue", hook=hook.__class__.__name__, error=str(e))

        # 2. 4 步流水线（按需复用 stage_cache）
        try:
            # Step 1
            if "step1" in ctx.stage_cache:
                ctx.structured = ctx.stage_cache["step1"]["structured"]
                log.info("step1_cache_hit", task_id=ctx.task_id)
            else:
                await self._update_status(ctx, DistillStatus.STEP1_STRUCTURING)
                await step1_structure(ctx, self.llm)
                ctx.stage_cache["step1"] = {"structured": ctx.structured.model_dump()}

            # Step 2
            if "step2" in ctx.stage_cache:
                ctx.rewrite = ctx.stage_cache["step2"]["rewrite"]
                log.info("step2_cache_hit", task_id=ctx.task_id)
            else:
                await self._update_status(ctx, DistillStatus.STEP2_REWRITING)
                await step2_rewrite(ctx, self.llm)
                ctx.stage_cache["step2"] = {"rewrite": ctx.rewrite.model_dump()}

            # Step 3
            await self._update_status(ctx, DistillStatus.STEP3_TTSING)
            await step3_tts(ctx, self.tts_client)

            # Step 4
            await self._update_status(ctx, DistillStatus.STEP4_CONCATENATING)
            await step4_concat(ctx)

            # 上传 + 写库
            await self._save_audio(ctx)
            await self._write_final_to_db(ctx)
            await self._update_status(ctx, DistillStatus.DONE)

            # 3. Post-hooks
            if self.post_hooks and self.session_factory is not None:
                async with self.session_factory() as session:
                    for hook in self.post_hooks:
                        try:
                            await hook(ctx, session)
                        except Exception as e:
                            log.warning("post_hook_failed_continue", hook=hook.__class__.__name__, error=str(e))

            log.info("distill_completed", task_id=ctx.task_id, duration_ms=(time.time() - start) * 1000)
            return ctx
        except Exception as e:
            log.exception("distill_failed", task_id=ctx.task_id, error=str(e))
            await self._update_status(ctx, DistillStatus.FAILED)
            await self._refund_quota(ctx)
            raise
```

class StageCacheHook:

    关键设计：
    - Redis key: stage:{task_id}:{step_name}
    - value: Pydantic model_dump_json()
    - TTL: 86400s（覆盖整个 Arq retry 窗口）
    - 失败兜底：Redis 不可用 → log warning，pipeline 不阻塞
    """
    async def __call__(self, ctx, step_name, output, db):
        try:
            client = redis_async.Redis(connection_pool=get_redis_pool())
            key = f"stage:{ctx.task_id}:{step_name}"
            value = output.model_dump_json() if hasattr(output, "model_dump_json") else json.dumps(output)
            await client.set(key, value, ex=86400)
        except Exception as e:
            log.warning("stage_cache_write_failed", step=step_name, error=str(e))

from stashbox.backend.common.models import Article, User as UserModel

async def route_tier(
    article: Article,
    user: UserModel,
    user_profile: UserListeningPattern | None,
    db: AsyncSession,
) -> Literal["simple", "full"]:
    """根据文章 + 用户画像选模型 tier。

    simple：GPT-4o-mini / Qwen2.5-7B（成本 ~1/5，听感中等）
    full：GPT-4o / Qwen2.5-72B / Claude Sonnet（成本高，听感优）

    规则（按优先级，第一个匹配即返回）：
    1. 强制 full：用户订阅是 pro / member + 反馈数 >= 10 + 历史评分均值 < 3.5
    2. 强制 full：article.raw_content 字数 > 3000 OR 来源 PDF/arxiv
    3. simple：article.raw_content 字数 < 800 AND 来源抖音/快讯 AND 用户评分均值 >= 4
    4. 其他：full（保守默认）

    失败兜底：异常 → 返回 "full"（保守）
    """
    try:
        # 规则 1
        if user.tier in ("pro", "member") and user_profile and user_profile.feedback_count >= 10:
            if user_profile.avg_overall_score and user_profile.avg_overall_score < 3.5:
                return "full"

        # 规则 2
        if article.raw_content:
            raw = article.raw_content
            if isinstance(raw, dict):
                content_text = raw.get("content_text", "") or ""
            else:
                content_text = str(raw)
            if len(content_text) > 3000:
                return "full"
        if article.source_type in ("pdf", "arxiv", "long_wechat"):
            return "full"

        # 规则 3
        if article.raw_content and len(str(article.raw_content)) < 800:
            if article.source_type in ("douyin", "short_news"):
                if user_profile and user_profile.avg_overall_score and user_profile.avg_overall_score >= 4.0:
                    return "simple"

        # 默认
        return "full"
    except Exception as e:
        import structlog
        structlog.get_logger("tier_router").warning("route_tier_failed_fallback_full", error=str(e))
        return "full"

### §2.8 风险清单

| 风险 | 影响 | 兜底 |
|---|---|---|
| **stage_cache 写 Redis 阻塞主流程** | 蒸馏时延 +50ms | async fire-and-forget；失败 log warning 不抛 |
| **few-shot 池污染**（低分文本入选） | 个性化反向优化 | 入选门槛 score_avg >= 4 + 运营人工抽查（每周 5-10 篇） |
| **画像漂移**（用户偏好变化） | 个性化效果下降 | 30 天权重衰减 + 重新聚类 |
| **自动重蒸风暴**（LLM 异常导致全评分低） | 队列积压 + 成本翻倍 | AutoRetryHook 限流：单用户 1 天最多 3 次自动重蒸 |
| **冷启动用户收到大众改写** | 体验降级 | 前 5 篇评分请求主动推送，5 篇后立刻切个性化 |
| **TTS 转码占 CPU** | 主 worker 卡顿 | 独立 ARQ 队列 audio_variant_queue，max_jobs=2 |
| **LLM 切换模型**（OpenAI 涨价） | 单篇成本涨 30% | TIER_MODEL_MAP 集中配置，admin-web 可热改 |
| **schema 演进**（few-shot 新增字段） | 旧池子兼容性 | 老数据 score_avg 缺失 → 默认 0，不入选 |
| **GDPR 删除**（用户注销） | 听感画像需清 | DELETE FROM user_listening_patterns WHERE user_id = ?（CP5.6.3） |
| **跨用户金句复用法律风险** | 被原作者投诉 | 决策点 §5.4：默认走「仅结构复用」（金句不跨用户） |

## §5 待 Hornet 拍板的决策点

### 决策 1 · 个性化是否作为付费墙？
- **A**：student ¥9 看大众改写，member ¥29 / pro ¥69 看个性化（推荐）
- **B**：所有用户都享受个性化，靠订阅分层做内容差异化
- **影响**：CP5.6.0 / CP5.7.0 的产品形态

### 决策 2 · 多码率策略选哪种？
- **A**：3 码率全部预生成（128k / 96k / 64k，OSS 存 3 份，存储 ×3）
- **B**：按需转码（首先生成 128k，用户切档时实时转，推荐）
- **影响**：CP7.3.0 的存储成本和实现复杂度

### 决策 3 · CP3.6.2 prompt cache 启用范围？
- **A**：Step1 / Step2 / system prompt 全加（推荐）
- **B**：只在 Step1（VL 模型贵）的 system prompt 加
- **影响**：单篇成本下降 50% vs 30%

### 决策 4 · few-shot 池跨用户复用边界？
- **A**：原文金句可以跨用户复用进 few-shot（成本最优）
- **B**：金句只能本人复用，跨用户只复用结构模板（隐私优先）
- **影响**：法务 + 个性化效果

### 决策 5 · 评测组从哪来？
- **A**：内部 3-5 人组成评测组（推荐，CP3.8.0 启动）
- **B**：外包给第三方评测公司
- **C**：靠用户评分自校准（省钱但不准确）
- **影响**：闭环 1 校准的 ground truth 质量
