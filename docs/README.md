## 🏗️ ADR（架构决策记录）

放在 [`decisions/`](./decisions/) 子目录。

**命名规范**：`ADR-NNNN-<slug>.md`，例如：
- `ADR-0001-选择-fastapi.md`
- `ADR-0002-cp1-cp8-节奏.md`
- `ADR-0003-d9-为核心移动入口.md`

**模板**：
```markdown
# ADR-NNNN: <决策标题>

## 状态
Proposed / Accepted / Deprecated / Superseded

## 背景
<为什么需要这个决策>

## 决策
<我们决定怎么做>

## 后果
<这个决策带来的影响>

## 参考
<v1 方案章节 / 外部资料>
```

**当前 ADR 清单**：暂无（v1 方案已包含 D1-D53 53 个决策点，未来新增决策才写 ADR）

## 🤝 与 KB / KB_mcp 的关系

- **KB**（本地知识库）：存放**项目相关的 SOP / 红线 / 经验**（跨项目可复用）
- **KB_mcp**（MCP 服务）：让 Hermes 能 **recall** + **upsert** KB 内容
- **docs/**（本目录）：存放**本项目的设计文档**（项目专属）

**原则**：设计决策放 docs/decisions/，通用经验 / SOP / 红线放 KB。
