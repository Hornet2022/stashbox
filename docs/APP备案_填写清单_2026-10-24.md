## 0. 先分清两个号（这是最容易搞混、也最容易被驳回的地方）

| | 网站 ICP 备案 | **APP 备案** |
|---|---|---|
| 备案对象 | 域名/网站 | **应用程序（包名）** |
| 备案号 | `鄂ICP备2026060816号` | `鄂ICP备2026060816号-1`（同号 + `-N` 后缀） |
| 现在状态 | ✅ 已过（2026-09） | ❌ **未提交** |
| 谁会查它 | 云厂商（80 端口拦截）、工信部抽查 | **国产 ROM 的安装器**（MIUI / 澎湃 / OPPO / vivo / 华为） |

**为什么手机会提示「未获得 ICP 授权」**：从 2023-04 起，国产 ROM 在**非应用商店渠道**安装 APK 时会联网查
**APP 备案状态**，查不到就弹「未查询到此应用的 ICP 备案信息 / 无法识别应用备案」。

⚠️ 这个提示**不是**说应用有病毒，也不是说域名没备案（域名早就过了）——
它是「这个**包**还没备案」的合规提示。**在 APP 备案通过前，它会一直弹**，
用户只能点「仍然安装」绕过。

⇒ **这是合规动作，不是 bug**，只能靠提交备案解决，代码侧绕不过去。

## 2. 提交后要做的两件事（**别只等备案通过**）

### 2.1 App 内必须公示备案号（法规硬要求）

《互联网信息服务管理办法》要求备案号在 **启动页或设置页底部**显著位置公示，
且格式要**完整、可机读、不可遮挡**（地域前缀 + 「备」字 + 编号 + `-N` 后缀）。

- 现状：域名已备案，但 **App 里一个字都没公示** ⇒ 已于 2026-10-24 补上
  （设置页 → 关于 → 「备案信息」一行，点开跳工信部查询页）。
- ⚠️ 备案通过后，把那行的号码从 `鄂ICP备2026060816号-1` **核对成系统给出的准号**
  （若系统给的不是 `-1` 而是别的后缀，以系统为准）。

### 2.2 申请通过前，用户端的临时说法

在 APP 备案通过前，安装时仍会弹「未查询到 ICP 备案信息」。
⇒ 这段时间请内测用户按「设置 → 更多安全设置 → 关闭『安全守护』/『应用安全验证』」，
或直接在弹窗点「仍然安装」。
