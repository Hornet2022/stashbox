## 0. 先看时限

- 第十二条：网站开通（ICP 通过）之日起 **30 日内** 到属地公安机关备案
- 第二十三条：不履行备案职责 → 警告，或停机整顿不超过 6 个月

> ⚠️ 30 日从 **ICP 审核通过日** 起算，不是从今天起算。
> 若 ICP 通过日距今已接近 30 日，优先提交。

### 2.2 网络接入服务商

**先说错法**（2026-10-23 实测已确认）：把接入商名称填成「**（嘉兴电信ISP）杭州网银互联科技有限公司**」是错的。

| | 网银互联 | 阿里云 |
|---|---|---|
| 是什么 | 杭州网银互联科技（IDC/ISP 牌照，地址西湖区），独立第三方 IDC | 阿里云计算有限公司 |
| 和我们什么关系 | **无任何关系**（只是与阿里云共同发起过"星云联盟"） | 服务器供应商 + ICP 备案接入商 |
| 你的 IP 归谁 | 否 | ✅ BGP origin **AS37963 Hangzhou Alibaba Advertising Co.,Ltd.** |

填成网银互联 = 向公安声明"本网站的流量由电信系 IDC 接入"，与实际不符 → **接入信息与实际部署不一致**，是明确的驳回理由。

**正确操作**：把「接入商所属地区」切到**名称为「阿里云计算有限公司」的那条记录所在的区**，再在「接入商名称」里选它。

| 表单字段 | 填什么 |
|---|---|
| 接入商所属地区管辖 | 境内（默认，已选） |
| 接入商所属地区 | 浙江省 / 杭州市 / **余杭区**（阿里云在平台登记的区；若下拉里阿里云那条挂的是西湖区就跟它） |
| 接入商名称 | **阿里云计算有限公司** |
| 网站接入方式 | **租赁虚拟空间** |

**自检技巧**：平台若要求手填接入服务商电话，填 **`95187`**（或官方现行文档写的 `4008013260`）+ 编码 `673959654`。
阿里云官方开发者社区明确：**「如填写服务商电话 95187 后出现系统报错，检查一下服务商所属区域选择是否正确」**
—— 也就是说，**电话校验不过 = 所属地区选错了区**。用这个报错来定位，比背文档靠谱。

> 地区口径有历史差异：阿里云官方现行文档写**西湖区**，开发者社区/百科等大量资料写**余杭区**。
> 结论：**名称必须对上「阿里云计算有限公司」，地区跟着这条记录走**。不要为了对某个区的记忆去凑。

> 注意：`杭州网银互联科技有限公司` 注册地址在**西湖区**，平台把它挂在滨江区/西湖区一带都出现过。
> 所以「某个区下拉里出现网银互联」是正常现象，**不是**「阿里云没在这个区」的证据。

备用：域名注册服务商电话 `010-65985888`。

> ✅ **这一组 2026-10-23 已按此填好，与阿里云官方文档一字不差，不需要改。**

> 注：老资料里接入商区域有「余杭区 / 滨江区」的说法，阿里云官方现行文档写**西湖区**。

### 2.4 服务类型

| 表单字段 | 填什么 | 理由 |
|---|---|---|
| 是否提供互联网交互服务 | **是**（已选） | 注册登录、收藏、订阅、评论/反馈都是真实存在的交互功能 |
| 网站类型 | **G 计算机应用类** | 产品形态是 Android 应用 + 工具（AI 把文章蒸馏成音频），G 覆盖「手机软件、应用工具」 |
| 为什么不选 D 社交文娱类 | — | D 的定义是「连接用户与用户（交友互动、游戏休闲、视听服务）」，本站不提供 UGC 社区/社交；视听只是内容形态，不是服务模式 |
| 为什么不选 A 网络基础类 | — | A1 接入服务类 / A2 域名注册解析类 / A3 CDN 加速服务类 / A4 安全服务类 —— 这四项是**给做这些业务的公司自己用的**（ISP、注册商、CDN、安企）。我们是**租用**别人的云主机，不是提供接入/解析/CDN/安全服务 |

**G 下面还有子项**（A 类展开后是 A1~A4 四个复选框，G 大概率同理）：
展开 G，挑语义最接近「**手机软件**」或「**应用工具**」的子项勾上。
若 G 展开后的子项里没有这两个语义、只有"系统支持/云计算"这类基础设施描述，
那就勾语义最接近"应用工具"的那项 —— 判据是**审核员看到你的网站后能对上的那个**（产品页 + 下载入口 + Android 应用）。

> 兜底口径（阿里云官方）：「如不确定，先选否，被驳回可改」。
> 但本站交互功能是实打实的，选「否」一旦被核查反而更麻烦 —— 选「是」+ G。

> ⚠️ **审核员是真人，会打开网站看**。他看到的是：一个 Android 应用的产品落地页 + 下载按钮。
> 所以备案类型要和"网站实际内容"对得上，这也是第 4 节里"先挂 ICP 备案号"必须排在提交之前的原因。

## 3. 提交后会发生什么

| 阶段 | 时限 | 谁审 |
|---|---|---|
| 受理 | 1 个工作日内 | 属地公安网安 |
| 审核 | 法定 30 自然日（实际 5~10 工作日） | 个人主体 → 负责人常住地网安 |
| 结果 | 短信 + 平台「系统通知」 | — |

- **交互式网站可能被要求面审或实地检查**（以短信通知为准）。要带：身份证、域名证书、服务器证明。
- 可能索要：**服务器区域证明（机房证明）**、**网站核验通知书** → 找阿里云备案客服（智能在线 ia.aliyun.com）出具。
- 服务器所在地网安部门代码（若被要求填）：**杭州 330100000000**。

## 3.5 提交之前：先把 ICP 备案号挂到首页底部（别拖到备案通过后）

阿里云《备案驳回FAQ》把这两条列为**明确驳回理由**：

> - 「已备案成功的网站底部未添加备案号」—— 审核人员发现已备案成功的网站底部没有工信部下发的备案号，会驳回
> - 「网站底部已添加备案号但未链接到工信部网站」—— 备案号必须指向 beian.miit.gov.cn
> - 「网站标题、名称与备案不一致」—— 页面标题要含备案里的网站名称

现状（2026-10-23 实测 `infra/web/index.html` 全文 + curl 首页正文）：
**没有任何 footer、没有 ICP 备案号、页脚位都不存在**。

✅ **已于 2026-10-23 做掉**（本节保留作决策记录）：
- 营销页与 `admin.stashbox.cn`（含**登录页** —— 审核员第一眼看到的就是它）
  都挂了页脚；
- 号码的唯一真相源是 `infra/web/filing.json`，
  `backend/deploy/fill-filing-numbers.py` 注入到两个站
  （两个站在**两个不同的 git 仓**里，号码写两遍迟早只改一处）；
- 源码留占位符，注入只发生在**发布产物**上（营销页出
  `infra/web/dist/index.html`；admin 走构建期 `VITE_ICP_NUMBER`）；
- 号码为空时整段页脚不输出（宁缺勿假）；
- 已挂上：`鄂ICP备2026060816号` → 链 `https://beian.miit.gov.cn`。

**还差公安备案号**（审核通过后才有）：拿到后填 `filing.json` 的 `psb`，
重跑注入即可（图标 + 编号 HTML 从阿里云「我的网站 → 下载备案编号图标」拿）。

公安审核是同一个性质的人工核查：网警会打开 `stashbox.cn` 看内容。
带着"首页空空如也、没有备案号"去提交，等于把已知驳回点主动递上去。

**动作顺序**：

1. 拿到 ICP 备案号 → 在 `infra/web/index.html` 加一个 footer，放 ICP 备案号（链到 beian.miit.gov.cn）+ 公安备案号位（先留空位，备案号下来再补）
2. rsync 发布 + reload nginx
3. curl 验证首页底部确实出现备案号
4. **然后**再提交公安备案

**footer 结构**（加在 `</body>` 前；`infra/web/index.html` 是自包含静态页，无构建，直接改这个文件）：

```html
<footer class="site-footer">
  <p class="site-footer-bans">
    <a href="https://beian.miit.gov.cn" target="_blank" rel="noreferrer">鄂ICP备XXXXXXXX号</a>
    <!-- 公安备案通过后补第二段（图标 + 编号） -->
  </p>
</footer>
```

```css
.site-footer{padding:28px 16px 40px;text-align:center;font-size:12px;line-height:1.9;color:rgba(255,255,255,.45)}
.site-footer a{color:rgba(255,255,255,.6)}
```

**验证**（改完必须做，别只信"我改了"）：

```bash
curl -s https://stashbox.cn/ | grep -o "鄂ICP备[0-9]*号"   # 必须有输出
```

> 两条都别省：ICP 号必须链 `beian.miit.gov.cn`，公安号必须链 `beian.mps.gov.cn`（阿里云驳回FAQ 明确：加了没链接也驳回）。

## 4. 通过后 30 日内必须做的事

1. 平台 → 我的网站 → 详情 → 「点击下载备案编号图标」+「点击复制备案编号 HTML 代码」。
2. 把图标 + 编号 HTML 贴到**网站首页底部显著位置**，链接到 `https://beian.mps.gov.cn`。
3. 同步把 **ICP 备案号**挂到首页底部并链到 `https://beian.miit.gov.cn`（工信部要求，当前站点缺）。
4. `admin.stashbox.cn` 属同一网站，一并挂。

通用代码示例（阿里云官方）：

```html
<p><img src="<备案图标路径>" width="20"/>
  <a href="https://beian.mps.gov.cn/#/query/webSearch?code=<备案号>" rel="noreferrer" target="_blank">鄂公网安备XXXXXXXXXXXXXX号</a></p>
```
