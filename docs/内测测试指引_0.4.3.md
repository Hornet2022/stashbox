## 一、这版改了什么：修「通知栏里没有播放控制条」

有内测用户反馈：**更新之后，后台播放时通知栏里那条控制条不见了。**

我们查过了，**先说结论**：不是这一版（0.4.2）改坏的 —— 我们把 0.4.1 和 0.4.2 两个包逐字节比对过，
通知的实现代码**完全一样**，两个包在真机上跑了四组对照（前台播放 / 切到后台 / 权限被重置后重新授权 /
息屏锁屏），**两个版本的表现也完全一样**。

真正的原因是：**通知权限被关掉之后，App 之前既不告诉你「关了」，也没给你任何能走通的办法。**

手机上「关掉通知」有两条路，两条都会导致同样的结果：

1. 你在系统设置里把「听匣」的通知关掉了（很多手机会自动关某些 App 的通知）；
2. 你在弹出来的「是否允许听匣发送通知」里点了「不允许」，而且点了不止一次 ——
   之后系统就**再也不弹那个框**了。

第 2 种是最容易被忽略的：**系统不弹框之后，App 再去请求也不会有任何反应**，
而之前 App 里的那一行还写着「点击开启」—— 你点了，什么都不会发生。

⇒ 这一版做的是：把「App 知道自己被关了，并且能带你走通」这件事做实。

| 以前 | 现在 |
|---|---|
| 设置里只有「推送通知」那一行，**找不到「通知栏控制条」** | 设置里**新增「播放通知」一行**，写清楚它管的就是通知栏那条控制条 |
| 权限被彻底拒绝后，点那一行**毫无反应** | 点那一行**直接跳到系统的通知设置页**，你把开关打开就完事 |
| 播放器里**什么都不说** | 播放页会出现一条提示：**「通知栏没有播放控制条，点这里去系统设置开启」** |
| 文案写着「点击开启」，但有时候点了并不会开 | 文案跟实际动作对齐：系统弹不出框的时候，文案说的是「去系统设置」 |

**这一版没有新增任何功能，也没有改动你的数据。**

## 二、怎么更新（两条路，任选一条）

### 路线 A：App 内更新（推荐）

1. 打开「听匣」
2. 进「**设置**」→ 点「**版本**」这一行
3. 弹出「有新版本」→ 下载 → 装完

### 路线 B：浏览器手动下载

1. 浏览器打开 https://stashbox.cn/downloads/latest.apk
2. 下载完点安装
3. 系统问「已存在该应用，是否覆盖安装？」→ 选「**安装** / 继续」

### ⚠️ 很重要：请「覆盖安装」，不要卸载重装

| 做法 | 你的登录状态 / 收藏 / 下载好的音频 / 历史进度 |
|---|---|
| **覆盖安装**（直接装上去） | **全都在** |
| 卸载重装 | **全部丢失**，还要重新登录、重新下载 |

如果手机提示「无法安装」或「签名不一致」，**别卸载**，截图发给我们 —— 那是包的问题，我们来修。

> 顺带说一句：**卸载重装会让通知权限回到「没问过」的状态**，
> 于是下次播放时系统会重新问你要不要通知 —— 那一刻答「允许」就好。

## 三、更新后请做这几件事

### 1️⃣ 确认版本

「设置」→「版本」应显示 **0.4.3 (16)**。

### 2️⃣ 检查一下通知栏

这版的重点就是它，所以请顺手看一眼：

1. 在 App 里播一篇文章（声音出来）；
2. 按 Home 键退到后台，或直接锁屏；
3. 下拉通知栏 —— **应该有一条带播放/暂停、快进快退的控制条**。

**如果没看到**，别急，按下面这招自己就能修：

| 步骤 | 说明 |
|---|---|
| 1 | 进「听匣」→「设置」 |
| 2 | 找到「**播放通知**」那一行（就在「推送通知」下面） |
| 3 | 点它 —— 如果弹出授权框，就选「允许」；如果直接跳到了系统设置页，就把「通知」开关打开 |
| 4 | 回到 App 继续播，控制条就回来了 |

> 播放器里也会出现一条黄条提示「通知栏没有播放控制条，点这里去系统设置开启」，点它可以直接跳过去。

### 3️⃣ 顺手用一轮（不用专门测，正常用就行）

- 剪藏一篇公众号文章（贴链接）
- 等它蒸馏出音频（一般 1～4 分钟）
- 播放一小段，听听声音和字幕
- 试**锁屏控制**：锁屏后能不能暂停 / 续播
- 试**断点续听**：退出 App 再进来，进度应接着上次

### 4️⃣ 请不要做这两件事

- ❌ **不要清除应用数据**（设置里的「清除数据 / 清除缓存」）
- ❌ **不要卸载重装**

理由：这些性能数据按「设备 + 安装」连续采集，中途清数据或重装会让数据断档 —— 反而帮不上忙。你要是不小心清了，告诉我们一声就行，不用担心。

## 四、遇到问题怎么反馈

**入口**：「设置」→「**意见反馈**」（或在文章详情页右上角「⋯ → 反馈」）

请带上这几样：

- 机型 + 系统版本（设置 → 关于手机）
- 「设置 → 版本」里看到的版本号
- 出了什么事（截图最好）
- 如果是「慢」，大概慢几秒、在什么网络下
- **如果是「通知栏没有控制条」**：请顺带截一张「设置 → 播放通知」那一行的图 ——
  它会直接告诉我们是「还没授权」「被你关掉了」还是「系统不再问了」

**特别欢迎**：任何你觉得「别扭」「说明不清」「找不到」的地方 —— 哪怕它不是 bug，那也正是我们要改的。你现在遇到的别扭，是内测最值钱的部分。

## 五、已知问题（先说在前面，免得多花时间）

| 现象 | 说明 |
|---|---|
| 剪藏某些网站失败，提示「没能读出文章正文，可能页面要登录，或者内容要等网页加载完」 | 我们的抓取只走普通网页通道，**动态渲染的页面（内容要等 JS 加载）和需要登录的页面读不到**。这不是你的操作问题，换个来源的链接就行。 |
| 蒸馏一直没动静 | 蒸馏要跑真实的大模型，通常 1～4 分钟。超过 10 分钟还没动静再反馈给我们。 |
| 播放时偶尔要等几秒才出声 | 正在收集这个数据（就是下面第六节第二项）。**如果你网络差，这个等待会明显变长** —— 这正是我们想知道的，请告诉我们你在什么网络下遇到的。 |
| 通知栏里没有播放控制条 | 看上面「三、2️⃣」那三步 —— 绝大多数情况自己就能修好。修不好请截图反馈，并附上机型与系统版本。 |

## 六、这一版我们做了什么（给愿意看细节的人）

**0.4.3（2026-10-26）**

- 通知权限的判断收口成**一份**，现在能分清三种情况：已经开了 / 还能弹系统授权框 / **只能去系统设置**
- 设置页新增「播放通知」一行（通知栏控制条与推送通知共用同一个系统权限，之前设置里**只有推送那一行**）
- 「系统不会再弹授权框」时，改为**直接跳到系统的通知设置页**，不再弹一个系统不会响应的框
- 播放器页新增提示条，把「为什么没有控制条」和「现在能做什么」直接摆出来
- 上一版（0.4.2）加的两个性能指标采集继续保留

**0.4.2（2026-10-25）**

- 加了「首屏加载」「音频启动」两个性能指标的客户端采集（数据只进我们的后台）
- 管理后台的总览页新增「月留存」卡片（运营看的，跟你的使用无关）
- 后台与客户端的事件名加了一层自动校验，防止埋点因为「名字对不上」而静默丢失

**没有别的改动 —— 你的数据、账号、文章都不会因为这次更新发生变化。**
